# Conductor Brief Format

Standing instructions for how to structure the daily command briefing. Agents running Conductor mode must follow this format exactly. This file takes precedence over any brief format described in the base system prompt.

---

## Purpose

The daily brief is not a task list. It is a daily expression of Brillect's Milwaukee market strategy. Every action surfaced must connect to at least one of the three strategic pillars and reflect ICP thinking. If an action doesn't credibly contribute to $2M–$4M in Milwaukee revenue, it should not appear.

---

## Three Strategic Pillars (Reference)

- **Pillar 1 — Lead with Advisory:** Surface assessment opportunities as entry points. Land and expand. Full lifecycle M&A, ERP/HCM, interim resources.
- **Pillar 2 — Strengthen Channel Partnerships:** Monthly touchpoint minimum with each partner. Lead with value first. M&A advisors, banks, law firms, PE operating partners.
- **Pillar 3 — Build Brand through Community:** AI events, finance/HR cohort groups, ACG/WICPA/TEMPO sponsorship and speaking. Become the convener, not just a vendor.

## ICP Trigger Events (Reference)

Always tag actions with the underlying trigger event:
- [Fresh PE acquisition]
- [Near exit / exit prep]
- [Post-acquisition integration]
- [Post-IPO finance build]
- [ERP / HCM transition]
- [Leadership change]
- [Rapid growth]
- [M&A activity]
- [Big 4 fatigue]
- [Channel partner referral]

## Pillar Balance Rules

- A brief that surfaces only Pillar 1 actions is incomplete — check Pillar 2 and 3 status.
- Pillar 3 (Community/Brand) is the most commonly neglected. If no Pillar 3 action has occurred in 5+ days, flag it and surface one specific action (event to attend, AI event planning step, speaking opportunity).
- Channel partner cadence (Pillar 2) should generate at least one touchpoint action per week across the partner network.
- PE sponsor and attorney channel moves should be treated as pipeline creation, not generic networking. Each move needs a trigger, relationship path, and value-first reason to contact.

## ICP Filter Rules

- Every action in Follow-Ups, Signal Watch, and Top 3 must be tagged with the underlying ICP trigger event.
- If an action cannot be tagged with a trigger event, question whether it belongs in the brief.
- Big 4 presence at a target is context, not a disqualifier. Note it and pair it with the "Big 4 fatigue" tag where relevant — it is an entry point, not a barrier. Friction scales with company size (see icp-refinements.md).

## Constraints

- Max 350 words total (excluding Top 3 Actions section)
- Bullets over paragraphs
- No fluff — every line must earn its place
- If pipeline value is unknown, note "pipeline value TBD — estimate needed"
- Never fabricate pipeline numbers or event details
